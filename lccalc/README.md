# README: Creating a Windows Executable with Cython and PyInstaller (For Windows Users)

Welcome to the ultimate guide for Windows users who want to turn their Python project into a shiny executable using **Cython** (for performance) and **PyInstaller** (for packaging). This guide will walk you through every step to create a fast, standalone `.exe` file for your Python application.

---

## Prerequisites

Before diving into the process, let’s make sure you have everything set up. You will need:

1. **Python 3.x** (preferably the latest stable version).
2. **Cython** (for performance boosts).
3. **PyInstaller** (to create the executable).
4. **Visual C++ Build Tools** (for compiling Cython code).
5. **A Virtual Environment** (optional but recommended for a clean workspace).

If you don’t have Python installed yet, grab it from the [official Python website](https://www.python.org/downloads/) and make sure to add it to your system PATH during installation.

---

## Step-by-Step Process

### 1. **Prepare the Python Code**

For this guide, we’ll assume your Python project has two files:
- `main.py`: This is the entry point to your application.
- `script.py`: This file contains your logic and will be compiled with Cython for improved performance.

Make sure your code works perfectly in Python first. There’s no point in creating an executable if your code isn’t behaving well already, right?

### 2. **Convert Python Code to Cython**

Let’s speed things up! To make the `script.py` file run faster, we will convert it to Cython (`.pyx` file) and then compile it.

#### Step 2.1: Rename `script.py` to `script.pyx`

Simply change the extension from `.py` to `.pyx`.

#### Step 2.2: Create a `setup.py` File

To compile your `.pyx` file, you’ll need a `setup.py` script. Here’s what it should look like:

```python
from setuptools import setup
from Cython.Build import cythonize

setup(
    ext_modules=cythonize("script.pyx"),
)
```

This tells Cython to compile `script.pyx` into a `.pyd` file.

#### Step 2.3: Compile the Cython Code

Now it’s time to compile! In your project directory, open a **Command Prompt** and run:

```bash
python setup.py build_ext --inplace
```

This will create the compiled `.pyd` file (on Windows, it will be something like `script.cp38-win_amd64.pyd`).

#### Step 2.4: Test the Cython Module

Make sure everything’s working by importing the compiled Cython module into your `main.py` file:

```python
import script  # Import the compiled Cython module
```

Test it by running `main.py`:

```bash
python main.py
```

If everything works, you're good to go!

### 3. **Package Your Application with PyInstaller**

Now that your code is Cythonized, it’s time to package it into a standalone Windows executable using **PyInstaller**.

#### Step 3.1: Install PyInstaller

If you haven't already, install PyInstaller using pip:

```bash
pip install pyinstaller
```

#### Step 3.2: Build the Executable

Run the following command to create your `.exe` file. This command tells PyInstaller to:

- Package everything into a single file (`--onefile`).
- Name the executable `LC_Calculator` (`--name=LC_Calculator`).
- Include the compiled Cython `.pyd` file (`--add-binary "script.pyd;."`).

```bash
pyinstaller --onefile --name=LC_Calculator --add-binary "script.pyd;." main.py
```

### What this does:

- **`--onefile`**: Combines everything into a single executable file (no messy folders).
- **`--name=LC_Calculator`**: Names the executable `LC_Calculator.exe`.
- **`--add-binary "script.pyd;."`**: Includes the compiled `script.pyd` (or `.so` if on Linux) with the executable.
- **`main.py`**: The main Python script to package.

After running the command, PyInstaller will create a folder called `dist/`, and inside it, you’ll find the executable `LC_Calculator.exe`.

#### Step 3.3: Test the Executable

Navigate to the `dist` folder and run your newly created `.exe` file to see if everything works:

```bash
cd dist
LC_Calculator.exe  # This is the Windows executable
```

## Optional Configurations (To Make It Fancy)

### Add an Icon to Your Executable

Want your app to look professional? Add a custom icon!

First, prepare an `.ico` file (you can convert an image to `.ico` format using online tools). Then use this command to add the icon:

```bash
pyinstaller --onefile --name=LC_Calculator --icon=app_icon.ico --add-binary "script.pyd;." main.py
```

This will make your app look super snazzy when running.

---

## Debugging Tips

- **Missing modules?**: If PyInstaller complains about missing modules, use `--hidden-import` to specify them. For example:

  ```bash
  pyinstaller --onefile --name=LC_Calculator --hidden-import=tkinter --add-binary "script.pyd;." main.py
  ```

- **PyInstaller Logs**: If something goes terribly wrong, check the logs generated by PyInstaller. They’re often full of helpful clues.
